# 归墟舆情分析 / Sentigraph 产品页文案

适用对象：官网产品介绍页、平台审核说明页、客户演示资料。

## 产品定位

归墟舆情分析 / Sentigraph 是面向企业公共舆情管理的证据分析与风险研判系统。它帮助企业把合法来源的公开评论、文章、视频说明、用户反馈、供应商样本和授权平台数据整理为可复核、可去重、可审计的舆情证据，并在此基础上生成分析结果、风险报告、趋势研判和模拟预演。

Sentigraph 的核心不是“绕过平台采集”，而是把企业已经合法获得或经授权获取的公共舆情材料，转化为结构化、可追溯、可复核的 EvidenceItem。

## Sentigraph 可以做什么

### 1. 证据归一化

系统支持将不同来源的事件材料统一为 EvidenceItem：

- 文章、帖子、视频、标题、正文、评论、回复；
- 点赞、回复、分享、浏览等互动指标；
- 手动 URL 证据；
- CSV/Excel 用户上传样本；
- 供应商 POC 样本；
- 搜索发现候选 URL / 标题 / 摘要；
- 未来经平台授权的官方 API 或 OAuth 数据。

所有证据都保留平台、来源类型、采集方式、证据类型、文本字段、URL、时间、互动指标、安全原始元数据和导入元数据。

### 2. 信任、去重、复核与审计

不同来源的证据可靠性不同。Sentigraph 会保留：

- provenance_type：证据来源类型；
- verification_status：验证状态；
- trust_label / trust_score：信任标签与分值；
- source_url_present：是否提供来源 URL；
- user_attestation_required：是否需要用户来源授权确认；
- risk_flags：来源不清、疑似密钥、截图转录、缺少时间、重复提交等风险标记；
- duplicate_group_id / duplicate_count：重复组与重复次数。

低信任、未验证、截图转录、缺少来源、重复或存在风险标记的证据会进入人工复核流程。复核动作包括通过、驳回、标记为弱证据、要求补充来源、合并重复和重置复核状态。复核历史会形成审计时间线。

### 3. 分析、报告与导出

Sentigraph 可基于案例中的可用证据生成：

- 情绪与话题概览；
- 高风险话题和争议点；
- 重复话术和异常集中度提示；
- 代表性评论或文本片段；
- 中文舆情分析报告；
- Markdown 报告导出。

报告基于当前导入或授权可用的证据，不代表全平台或全网覆盖，也不构成事实认定或法律意见。

### 4. 风险趋势与模拟预演

系统可基于本地案例快照进行风险趋势研判，并提供聚合层面的 Simulation Lab 预演，用于比较不同沟通策略在假设条件下的潜在影响。

Simulation Lab 是离线确定性的内部辅助工具，不会执行真实平台操作，不会自动发布内容，不会自动删除或屏蔽内容，也不会对个人进行定向影响。

## 数据边界

Sentigraph 当前遵循以下边界：

- 默认运行在 mock/offline 模式；
- 可选 YouTube 真实数据演示仅在本地配置官方 YouTube API Key 时使用；
- 抖音、Bilibili、小红书、微博、Reddit 等真实接口仍待官方权限、OAuth、回调地址、测试账号或接口范围确认；
- Search Discovery、RSS Mock、GDELT Mock 当前仅为静态候选元数据演示；
- LLM provider 当前为 mock，不调用真实大模型 API；
- MediaCrawler / OpenClaw 等外部工具不作为产品核心采集器或生产数据源；
- 用户上传、人工录入、供应商样本和截图转录不会被自动视为已验证。

## 禁止用途

Sentigraph 不应用于：

- 未经授权的私有数据采集；
- Cookie / 登录态抓取；
- 验证码或反爬机制绕过；
- 代理规避或隐藏访问；
- 私信、私密群组、付费墙内容、账号私有数据采集；
- 个人画像、影响力评分或定向说服；
- 自动执行真实内容审核、封禁、删除、发布、私信或营销动作。

## 典型使用场景

### 品牌危机复盘

导入公开评论、投诉、媒体报道和客服反馈样本，整理核心争议点、情绪倾向和高风险话题，形成内部复盘报告。

### 产品反馈分析

将用户评论、应用商店反馈、论坛帖子和手动 URL 证据统一归档，识别质量、交付、价格、服务等主题。

### 平台评论管理准备

在获得平台官方权限前，先通过 mock/scaffold、CSV 样本和人工证据验证分析链路；获得官方权限后再接入授权范围内的数据。

### 供应商数据 POC

使用供应商提供的安全样本文件进行字段完整性、重复率、来源可追溯性、时效性、合规风险和成本评估，不在 POC 阶段调用供应商 API。

### 舆情策略预演

基于聚合证据和离线模型，对澄清、道歉、进度更新、第三方证据说明等策略进行场景比较，帮助团队在人工审核后制定沟通方案。
