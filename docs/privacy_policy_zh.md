## 1. 我们处理哪些数据

在您使用归墟舆情分析 / Sentigraph 时，我们可能处理以下类别的数据：

### 1.1 账号与联系信息

当您通过官网、邮件、表单或商务沟通联系我们时，我们可能处理您的姓名、公司名称、职位、联系电话、电子邮箱、沟通内容和业务需求。

### 1.2 用户上传的舆情证据

您可能上传或录入用于分析的 CSV/Excel 文件、文章标题、正文摘要、评论、回复、互动指标、公开 URL、发布时间、公开作者标签、来源平台标签和相关说明。

系统默认只保存规范化后的 EvidenceItem 和安全元数据，不以默认行为保存原始上传文件。上传数据中的 API Key、access token、refresh token、client secret、password、cookie 等疑似密钥字段会被拦截、删除或脱敏处理。

### 1.3 手动 URL 证据

您可以手动录入公开 URL、标题、正文、评论、作者标签、时间和指标。Sentigraph 不会自动访问、抓取或解析该 URL。URL 仅作为来源上下文和人工复核线索保存。

### 1.4 供应商样本数据

在进行供应商 POC 时，您可能导入供应商提供的样本文件。此类数据会被标记为 data_vendor 来源，并根据供应商说明、合同、授权、保留期限、删除同步和个人信息处理情况进行复核。供应商样本不等同于平台官方验证数据。

### 1.5 可选授权平台数据

在获得您授权并完成平台官方审核、OAuth、权限范围、回调地址和令牌配置后，系统未来可能处理授权范围内的平台公开数据或账号授权数据。当前产品中，YouTube 真实数据仅作为本地可选演示路径，抖音、Bilibili 等真实接口仍处于官方权限或应用审核阶段。

### 1.6 系统运行与安全日志

为保障服务安全和排障，我们可能记录请求时间、接口路径、状态码、错误类型、浏览器或设备信息、操作事件、导入任务状态、复核操作记录和审计时间线。日志不应包含 API Key、Cookie、OAuth token、client secret 或 `.env` 值。

## 2. 我们如何使用数据

我们使用上述数据用于：

- 提供舆情证据导入、归一化、去重和复核；
- 生成情绪、话题、风险、报告、趋势和模拟预演结果；
- 展示证据来源分布、信任标签、复核状态和审计记录；
- 处理客户咨询、演示、部署和技术支持；
- 保障系统安全、排查错误、改进产品体验；
- 履行合同、合规和法律义务。

我们不会将用户上传证据自动视为已验证事实。截图、转录文本、供应商样本、搜索候选和人工录入材料均需要人工复核。

## 3. 数据来源与用户责任

用户应确保上传、录入或提交给 Sentigraph 的数据来源合法，且有权用于舆情分析、内部报告或约定用途。用户不得提交未经授权的私密数据、登录态数据、Cookie、访问令牌、私信、私密群组内容、付费墙内容或其他违反法律法规及平台规则的数据。

## 4. 存储与保留

我们会根据业务需要、合同约定和法律要求保存必要数据。对于用户上传文件，系统默认不保存原始文件，仅保存规范化证据和安全元数据。案例、报告、复核记录和审计日志的保留期限可根据企业部署和合同约定配置。

当服务终止、用户申请删除或合同要求删除时，我们将按照适用约定处理删除、匿名化或停止使用。对于已经生成的聚合报告或审计记录，保留方式应以合同、法律要求和企业合规政策为准。

## 5. 共享与委托处理

未经您的授权或法律要求，我们不会向无关第三方出售您的上传证据。为提供服务，我们可能在以下场景共享或委托处理必要信息：

- 云服务器、数据库、对象存储或安全运维服务；
- 企业客户指定的部署、运维或数据供应商；
- 法律法规、监管要求、争议处理或安全事件响应。

如涉及个人信息处理，我们将按照适用法律和合同要求签署必要的数据处理协议、保密协议或安全条款。

## 6. 安全措施

我们采取合理措施保护数据安全，包括：

- 不在接口或日志中返回密钥、Cookie、Token 或 `.env` 值；
- 对疑似密钥字段进行脱敏或拒绝保存；
- 将证据和复核记录以结构化方式保存；
- 对低信任、缺少来源、重复、截图转录或风险标记证据进行人工复核；
- 禁止 Cookie 抓取、登录绕过、验证码绕过、反爬绕过和 MediaCrawler 集成作为产品采集路径。

## 7. 您的权利

在适用法律范围内，您可以联系我们行使以下权利：

- 查询、更正或补充您的联系信息；
- 请求删除或停止处理您提交的数据；
- 请求导出或获取您提交的数据副本；
- 撤回授权或限制特定数据处理；
- 对个人信息处理提出投诉或咨询。

请通过 [contact@guixutech.com] 联系我们。我们可能需要验证您的身份或企业授权关系。

## 8. 未成年人信息

Sentigraph 面向企业和组织使用，不面向未成年人提供个人服务。用户不得主动提交未成年人个人信息、敏感个人信息或与分析目的无关的个人数据。

## 9. 政策更新

我们可能根据产品、法律法规或业务变化更新本政策。更新后将在 guixutech.com 公示，并标明生效日期。
