# Opinion Ecosystem 8S-16-NR Trusted Playtest Without Recording Gate v0.1

## A. Purpose

Trusted playtest without recording is possible later, but it is not approved now.

This document defines the gate that must be satisfied before any future no-recording trusted playtest.

## B. Entry Criteria

Trusted playtest without recording may begin only after:

- internal self-guided walkthrough QA completed
- route confusion issues fixed or documented
- no visible UI/runtime blockers
- generated-run click works
- boundary language is visible
- no secrets/private paths/raw identifiers
- no generated response text
- no publish/send/post/execute CTA
- playtest script prepared
- observer note template prepared
- feedback triage template prepared

## C. Allowed Later Scope

Allowed later, only after explicit approval:

- 1 to 3 trusted people
- supervised local demo or private screen-share
- no public link
- no public posting
- no analytics
- no accounts
- no payment/sponsor flow
- no recording requirement
- no screenshot requirement

## D. Blocked Scope

Blocked:

- public beta
- public release
- mass testing
- production deployment
- real API/LLM
- collector run
- private collector integration
- real package row parsing
- Evidence Layer write
- production case / analysis_run
- generated public response
- publish/send/post/execute
- target_user_list / persuasion_score / truth_score / official_verified / prediction_probability
- psychological_profile / personality_diagnosis

## E. Success Criteria

A future trusted playtest without recording can be considered successful only if:

- the trusted person understands this is selected sample only
- the trusted person understands it is not full-web/full-platform coverage
- the trusted person understands generated run is local fixture output
- the trusted person understands PeopleCluster is an anonymous aggregate proxy
- the trusted person understands ResponseStrategyComparison is human-review-only
- the trusted person does not think the system is live crawling or officially verifying facts
- the trusted person can follow the Dong/Sun route without getting lost
- feedback can be recorded as simple notes without personal sensitive data

## F. Not Approved Now

8S-16-NR does not approve trusted playtest. It only defines the future gate.

Do not contact testers, create accounts, publish links, run public beta, collect analytics, or execute platform actions in this phase.
