# Second-round Playtest Feedback Triage v1

Status: playtest triage and planning note. This document does not implement runtime behavior.

## 1. Raw Feedback Summary

- Dong Lu / Sun Jihai public event detail can navigate to the Opinion Ecosystem Sandbox, but the Sandbox may still appear to be in the Helldivers PSN context.
- T0-T6 replay should automatically use Dong/Sun historical presets after entering from the Dong/Sun event.
- The Dong/Sun sample selector can be found manually, but event-specific context should initialize automatically.
- The Dong/Sun Sandbox visualization can feel sparse or unclear for a selected sample with hundreds of evidence rows.
- The pink / orbiting marker is not self-explanatory.
- The T0-T6 phase control is too far below the main canvas.
- The user expected visible "poster / person / social / weight" analysis. This must be reframed as anonymous PeopleCluster and aggregate behavioral proxy metrics, not personality diagnosis.
- The user expected the demo to lead toward a professional analysis case.
- The private collector should be treated as an external local-file evidence provider, not a Sentigraph built-in crawler.

## 5. Product Direction Shift

The feedback shifts the next product need from more frontend polish or broad refactor toward a minimum backend automation path:

```text
event query
-> AnalysisRequest
-> external local file exchange request
-> provider result metadata
-> Evidence Export package metadata
-> review-ready case candidate
-> case snapshot
-> analysis_run
-> report / Sandbox candidate
```

This should remain a local-file exchange MVP. It should not become an HTTP/HTTPS provider API or a live crawler.

## 6. Safe Terminology

Use:

- anonymous PeopleCluster
- aggregate discussion cluster
- behavioral proxy metric
- stance strength
- activity weight
- expression intensity
- bridge score
- amplification tendency
- fatigue / exit tendency
- source trust profile
- sample-based heuristic
- selected public sample
- analysis_run snapshot

Avoid:

- personality diagnosis
- psychological profiling
- individual persuasion scoring
- real-person tracking
- real identity inference
- official verification
- causal proof
- full-web truth

## 7. What Must Not Be Implemented Or Claimed

- No full-web or full-platform coverage.
- No real APIs.
- No URL fetching or scraping.
- No MediaCrawler integration.
- No OpenClaw production ingestion.
- No HTTP/HTTPS provider API in the MVP.
- No cookies, tokens, sessions, browser profiles, or anti-bot bypass.
- No raw author identifiers exposed.
- No production Evidence Layer write from this playtest fix.
- No production case, review queue, dedup, analysis, report, Sandbox, or public event runtime generated by this document.
