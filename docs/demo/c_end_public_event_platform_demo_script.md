# C 端公共事件平台 Demo 脚本（v1）

## 1. 演示目标

本次演示用于验证 C 端公共事件平台在“事件可见、证据可理解、风险可审查”三方面的体验闭环。目标不是展示全量实时舆情抓取，也不是提供官方验证结果。

演示边界：

- 前端原型（frontend-only）
- 已选择公开样本（selected public sample）
- 不代表全网覆盖 / 不代表全平台覆盖 / 不代表全线程覆盖
- 不代表官方认证或因果结论
- 不调用真实 API，不调用真实 LLM，不执行平台真实操作

## 2. 受众

- 普通用户
- 游戏 / 动漫 / 品牌社区用户
- MCN / 公关 / 品牌 / 游戏社区运营
- 潜在投资人前置材料

演示中需要根据受众调整解释深度。

## 3. 3 分钟演示脚本

### 0:00–0:20 项目定位与边界
- 打开首页或 App 入口，简述“Sentigraph 是公共事件可视化与舆情风险模拟工具（本地样本原型）”。
- 明确说：
  - “这是 C 端体验原型，不是抓取全网的生产系统”
  - “当前为选定公开样本，非官方核验”
  - “小球是匿名群体簇，不是个人画像”

### 0:20–0:50 事件广场
- 点击：事件广场（事件列表）
- 讲解：这里展示的是公开事件入口和事件入口统一格式。
- 展示列表字段与可进入的事件详情。
- 强调不要承诺全量监测。

### 0:50–1:30 Helldivers 公开事件详情页
- 打开：Helldivers 事件页
- 讲解：
  - 这是一个示例事件，展示“事件主视图 + 样本说明 + 可进入的分析模块”。
  - 解释样本来源标识与时间范围。
- 指出风险边界文案：
  - 不是官方验证
  - 非因果推断
  - 不代表所有平台与所有相关帖子

### 1:30–2:10 查看生态沙盒
- 进入生态沙盒入口（查看生态沙盒）
- 切换到：V2 ecology view
- 切换数据源：Helldivers PSN sample
- 讲解：
  - EchoBox 表示讨论语境容器与事件演化空间
  - PeopleCluster 表示匿名群体簇
  - InfluenceCore 表示内容/叙事/媒体/官方/梗核主题核心节点
- 指出：这不是真实个人身份，不做人群追踪。

### 2:10–2:45 Sandbox 场景与时间线
- 点击 T0–T6 时间线
- 至少示意性展示 2–3 个阶段（如 T0、T3、T5）
- 讲解：
  - 变化用于说明“模拟传播路径与策略干预假设”
  - 不承诺真实平台真实热度绝对值

### 2:45–3:00 请求与投票 + B 端咨询 mock
- 打开请求/投票入口
- 说明这是“请求分析 / 投票支持 mock”，仅用于交互路径演示
- 展示 B 端咨询 mock CTA，说明后续是人工接入与商务线索管理。
- 收尾：重申边界与安全文案。

## 4. 8 分钟演示脚本（可用于正式演示前训练）

### 0:00–1:00 项目边界与安全声明
- 明确说明：前端本地原型、样本驱动、非全网覆盖。
- 逐条读出“不可声明项”：
  - 非实时爬取结果
  - 非官方验证
  - 不代表因果关系
  - 不执行平台动作

### 1:00–2:00 事件广场
- 展示入口、列表筛选/分组逻辑、事件卡片布局。
- 解释为什么先从事件入口入手而非直接“全局大盘”。

### 2:00–3:00 Helldivers 公开事件页
- 逐条讲解事件简介、样本限制、可行动项。
- 强调“selected public sample”与“非完整覆盖”。

### 3:00–5:00 生态沙盒 V2 + mapping card
- 进入生态沙盒
- 切 V2 ecology view、Helldivers PSN sample
- 展示 Mapping Contract Card
- 讲解模型含义：
  - EchoBox
  - PeopleCluster
  - InfluenceCore
  - DeconstructionCore（如有）
  - ResponseTempo（如有）
  - ReputationMemory（若可见）
- 强调影响因子可解释、但不做真实性背书。

### 5:00–6:20 T0–T6 时间线逐步演示
- 依次触发：T0 / T1 / T2 / T3 / T4 / T5 / T6
- 指出每一阶段下图形与指标变化仅为模拟演化示意。
- 说明为什么不能将其等同“自然传播真实测量”。

### 6:20–7:00 请求分析 / 投票支持
- 演示 mock 交互：提交/查看 mock 请求和 mock 投票。
- 强调数字仅为演示流，非真实舆情热度。

### 7:00–8:00 B 端咨询 CTA + 总结
- 打开 B 端咨询 mock 流
- 总结：
  - 这个版本适合做事件摘要与决策沟通支持
  - 不是替代法务、舆情部门、客服执行系统
- 给出下一步：扩展公开样本、提升用户解释文案、加入真实平台接入前置审批。

## 7. 不要宣称的点
