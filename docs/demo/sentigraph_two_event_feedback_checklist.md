## Confusion Points

Check whether the user confused:

- Event Plaza with a real hot ranking.
- Request / vote mock with natural public heat.
- Sandbox historical replay with guaranteed prediction.
- Evidence sample with full-web or full-platform coverage.
- B-end report sample with real export runtime.
- Response Strategy Lab with an active strategy engine.
- PeopleCluster with real people.
- InfluenceCore with a real person.

## Trust Concerns

Ask:

- What made you trust or distrust the sample?
- Was the limitation copy visible enough?
- Did the phrase controlled candidate public sample feel clear?
- Did `review_needed` feel clear?
- Did `source_url_provided_unverified` feel clear?
- What additional proof would you need before using this in a professional setting?

## Willingness to Use / Pay

Ask:

- Would you use the C-end event page for public understanding?
- Would you use the B-end report sample for internal communication?
- Would you pay for an event-specific report if evidence sourcing and review are clear?
- What would need to be added before paid use?
- Would you pay for Search-to-Report after provider and compliance gates are complete?

## Suggestions for Next Event

Ask:

- What event should be analyzed next?
- Why is that event suitable?
- What public evidence sources would be lawful and reviewable?
- Is the event sensitive enough to require additional privacy review?
- Should it be C-end public, B-end private, or internal-only?

## Red Flags

Record immediately if the user thinks Sentigraph is:

- Live crawling the web.
- Officially verifying truth.
- Predicting outcomes with certainty.
- Producing full-web or full-platform coverage.
- Executing real platform actions.
- Creating fake consensus.
- Supporting covert manipulation or targeted persuasion.

## Safe Feedback Recording Rules

- Do not collect sensitive personal data.
- Do not collect private platform data.
- Do not record login, profile, cookie, session, or private account state.
- Do not include raw author identifiers or profile links in feedback notes.
- Keep feedback about product comprehension, trust, clarity, and next-event selection.
- Keep any commercial-interest note at organization or role level, not individual profiling level.
