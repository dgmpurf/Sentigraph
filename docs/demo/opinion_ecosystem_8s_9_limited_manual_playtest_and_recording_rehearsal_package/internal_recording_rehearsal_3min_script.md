# Internal Recording Rehearsal 3-minute Script

## Purpose

This is an internal rehearsal script for a short Sentigraph C-end to B-end demo flow. It is not a public recording, not a launch asset, and not proof of production deployment.

## Exact Route Sequence

1. `/#/demo`
2. `/#/public-events`
3. `/#/public-events/donglu-sunjihai-youth-football`
4. `/#/opinion-ecosystem?sample=donglu-sunjihai-youth-football`
5. click generated-run panel
6. show boundary labels and module outputs
7. `/#/reports/donglu-sunjihai-youth-football-sample`
8. close with selected sample / local demo / human review required boundary

## 0:00-0:25 Intro

Click: open `/#/demo`.

Say:

> 这是本地 demo，用来演示 Sentigraph 如何把一个 selected sample only 的公共事件样本整理成事件页、生态沙盒和报告样例。它不是全网全量，不是官方验证，不是因果证明，也不是预测。

Avoid clicking:

- real account login
- external links
- any route that has not passed pre-flight

## 0:25-0:55 Event Plaza

Click: open `/#/public-events`.

Say:

> 公共事件广场是本地 demo 事件入口，不是实时热榜，也不代表自然公共热度。这里的事件用于说明产品体验和边界。

## 0:55-1:25 Dong/Sun Event Detail

Click: open `/#/public-events/donglu-sunjihai-youth-football`.

Say:

> 这是董路 / 孙继海青训争议的受控候选公共样本页。它展示事件摘要、样本覆盖、讨论结构和进入生态沙盒的入口。它不代表全平台、全网或完整讨论线。

## 1:25-2:15 Opinion Ecosystem Generated Run

Click:

1. open `/#/opinion-ecosystem?sample=donglu-sunjihai-youth-football`
2. click `Load backend local generated run`
3. pause on boundary labels and module cards

Say:

> generated run 是本地 fixture 输出，不是生产分数。PeopleCluster 是匿名聚合群体 / 行为代理，不是真实个人。InfluenceCore 是内容、叙事、官方、媒体或 meme 核心，不是人群小球。ResponseStrategyComparison 只用于人工复核，不生成公开回应，也不会自动执行任何平台动作。

Avoid clicking:

- publish / send / post / execute if ever visible
- routes that show a visible 500

## 2:15-2:50 B-end Report Sample

Click: open `/#/reports/donglu-sunjihai-youth-football-sample`.

Say:

> B-end 报告样例展示结构和商业价值：证据覆盖、风险节奏、沟通窗口和建议动作框架。建议动作不是自动执行，也不是官方结论。

## 2:50-3:00 Closing Boundary

Say:

> 这只是 selected sample / local demo / human review required 的展示。它不是全网全量，不是官方验证，不是因果证明，不是预测，也不生成公开回应或自动执行平台动作。
