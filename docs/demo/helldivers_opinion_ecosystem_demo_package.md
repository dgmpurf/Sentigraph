# Helldivers Opinion Ecosystem Demo Package

## 1. Package purpose

This package helps organize the Helldivers 2 / PSN Opinion Ecosystem Sandbox demo for review, recording, screenshot capture, and external explanation.

It is designed to make the demo easy to understand without overstating what the current system proves.

Required boundary:

- This is a frontend-only local demo.
- It uses a selected public sample.
- It is not full-web coverage.
- It is not full-platform coverage.
- It is not full-thread coverage.
- It is not official verification.
- It is not causal proof.
- It does not execute real platform actions.
- It does not call real APIs or LLMs.
- PeopleCluster balls represent anonymous groups/clusters, not real individuals.
- InfluenceCore nodes represent content / narrative / official / media / meme cores, not people balls.

## 2. Intended audience

- Internal review: align product framing, demo flow, and safety language.
- B-end customer demo: explain public-opinion structure, evidence limits, and response preview.
- C-end public demo preview: show an understandable, non-sensitive sandbox experience.
- Platform/vendor/cooperation review: demonstrate compliance-oriented boundaries and no unauthorized collection behavior.

## 3. What this package proves

- The Opinion Ecosystem Sandbox can run as a frontend-only local demo.
- The Helldivers PSN small sample mode can be selected and visualized.
- The UI can show EchoBox, PeopleCluster, InfluenceCore, DeconstructionCore, Camp Dynamics, ResponseTempo, sample status, and mapping contract information.
- The scenario controls can support a practical explanation of response timing and narrative change.
- Safety copy is visible and suitable for review: selected sample, limited coverage, no official verification, no causal proof.

## 4. What this package does not prove

- It does not prove full-web monitoring.
- It does not prove full-platform monitoring.
- It does not prove full-thread reconstruction.
- It does not prove official verification of Reddit, Steam, PlayStation, or other platform data.
- It does not prove real-time scraping or live data access.
- It does not prove causal effect of any response strategy.
- It does not prove production simulation or real-world execution.
- It does not prove that individual users can or should be modeled.

It uses a selected public sample from the Helldivers 2 / PSN account linking controversy to show how evidence can be mapped into anonymous PeopleCluster groups, InfluenceCore narrative nodes, and response scenarios. The demo is for communication, review, and product explanation. It is not full-web coverage, not full-platform coverage, not official verification, and not causal proof.”

## 8. Unsafe claims to avoid

Avoid saying:

- “全网舆情已完整采集”
- “全平台数据已接入”
- “官方验证了 Reddit / Steam 数据”
- “实时抓取平台内容”
- “自动证明某策略有效”
- “真实用户被逐个建模”
- “系统执行真实平台操作”
- “这是生产级仿真”

Use instead:

- “选定公开样本”
- “本地前端演示”
- “结构化观察”
- “匿名群体簇”
- “叙事核心”
- “回应策略预览”
- “需结合人工复核”
