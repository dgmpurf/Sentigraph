# Sentigraph Two-Event Recording Script - 3 Minutes

## One-Sentence Positioning

Sentigraph is a public-opinion evidence analysis and explanation prototype that helps users understand public event structure, sample boundaries, local historical replay, and report-style decision support.

## What Sentigraph Is

Sentigraph organizes selected public evidence into readable event pages, anonymous discussion clusters, narrative cores, local historical replay views, and fixed B-end report samples.

## What Sentigraph Is Not

Sentigraph is not a full-web crawler, not a real-time monitoring system, not official verification, not causal proof, not a prediction guarantee, not a crawler product, and not a tool for covert manipulation or targeted persuasion.

## 3-Minute Script

### 0:00-0:25 Opening

Click: `/#/demo`

Say:

"This is Sentigraph, a local demo for public-opinion evidence explanation. It shows how public samples can become event pages, sandbox views, and report-style summaries. The current demo is frontend-only and sample-based. It is not full-web coverage, not official verification, and not a prediction engine."

Do not claim:

- Full-web collection.
- Real-time monitoring.
- Official verification.

### 0:25-0:55 Event Plaza

Click: `/#/public-events`

Say:

"Event Plaza is the entry point for demo events. It is not a real hot list. It lets us compare two event chains: an international game-community sample and a Chinese sports public-opinion sample."

Mention:

- Helldivers / PSN selected public sample.
- Dong Lu / Sun Jihai controlled candidate public sample.
- Request and vote counts are mock signals, not natural heat.

### 0:55-1:30 Helldivers Event Chain

Click:

- `/#/public-events/helldivers-psn`
- `/#/opinion-ecosystem`

Say:

"The Helldivers example shows an earlier selected public sample. In the Sandbox, EchoBox means discussion context, PeopleCluster means anonymous groups, and InfluenceCore means content or narrative cores. This is local historical replay, not full-platform reconstruction."

Do not claim:

- Official verification of platform data.
- Full-thread reconstruction.
- Real platform action.

### 1:30-2:05 Helldivers B-End Report Sample

Click: `/#/reports/helldivers-psn-sample`

Say:

"The B-end report sample shows how the same sample can be organized for internal communication. It is a fixed frontend sample, not a dynamic export. It does not create PDF, Markdown, or briefing deck files."

### 2:05-2:40 Dong/Sun Event Chain

Click:

- `/#/public-events/donglu-sunjihai-youth-football`
- `/#/opinion-ecosystem?sample=donglu-sunjihai-youth-football`

Say:

"The Dong/Sun sample demonstrates a Chinese public-opinion case. It remains a controlled candidate public sample. Evidence is review_needed and source_url_provided_unverified. The local historical replay helps explain response tempo and reputation memory, but it is not a prediction."

### 2:40-3:00 Dong/Sun B-End Report Sample and Roadmap

Click: `/#/reports/donglu-sunjihai-youth-football-sample`

Say:

"The Dong/Sun B-end sample demonstrates report value: executive summary, evidence coverage, source structure, risk and opportunity, and planned-only Response Strategy Lab. The future roadmap is Search-to-Report: discovery, review, evidence import, sandbox explanation, and report generation after provider and compliance gates are ready."

Closing:

"The value is transparent explanation and evidence-backed context. The current version does not claim full coverage, official verification, or guaranteed outcomes."

## Required Boundary Lines

- selected public sample
- controlled candidate public sample
- local historical replay
- evidence coverage limitation
- review_needed
- source_url_provided_unverified
- planned-only
- transparent explanation
- evidence-backed context

## Avoid Saying

- "Full-web."
- "Real-time."
- "Officially verified."
- "Guaranteed prediction."
- "Crawler product."
- Any language implying covert manipulation, fake consensus, or targeted persuasion.
