- [ ] 前端服务可访问

- [ ] 事件广场可打开
- [ ] Helldivers 公开事件详情可打开

- [ ] V2 ecology view 可切换

## 2. 录制清单（建议）

- 打开事件广场，停留 3–5 秒
- 进入 Helldivers 详情页，停留 5–8 秒
- 进入生态沙盒并切到 V2，停留 8–10 秒
- 依次切换 Helldivers PSN sample + 3 个典型时间点（如 T0/T3/T5）
- 展示 Mapping Contract 与风险说明卡
- 打开请求 / 投票 mock，展示仅为 mock
- 打开 B 端咨询 mock CTA
- 最后再次回到边界文案停留 5 秒

## 3. 反馈会清单

### 会前
- 确认录屏与麦克风状态
- 准备反馈评分表（清晰度、实用性、可信度等）
- 准备红线问题清单

### 会中
- 强制复述：
  - 这是前端本地原型
  - 样本为公开选样，不代表全网
  - request/vote 是模拟入口，不为真实热度

### 会后
- 记录评分与反馈
- 标记误解项与红线事件
- 做 24 小时内修订清单

## 5. 分享会后材料

- 演示脚本（本文件）
- 反馈计划（feedback plan）
- 反馈记录表（评分 + 备注 + 红线）

- 快速修复清单

## 6. 不能做的事（发布前审查）

- 不得声称“全网实时 / 全平台 / 官方官方验证”
- 不得把用户投票当作真实热度
- 不得暗示“操控公众舆论”或“自动化决策执行”
- 不得遗漏 “PeopleCluster 非实名群体簇” 与 “InfluenceCore 非个体球体”说明
- 不得承诺平台合作或官方 API 已接入（除非对应审批完成）

## 7. 安全与合规提醒

- frontend-only 本地 demo
- 已选择公开样本
- 不调用真实 API / LLM
- 不执行平台真实动作
- 不提供个人追踪、私域收集、敏感平台凭证
- 仅在内部讨论与受邀用户反馈场景使用

## 8. 内部分享建议

- 给普通用户：强调“事件看懂、边界清楚、无全量承诺”
- 给 B 端/合作方：强调“事件复盘效率、风险沟通、商业咨询入口、可扩展性”
- 给投资前置：强调“样本驱动、可审查边界、逐步产品化路径”
