# Helldivers Opinion Ecosystem 录屏脚本

## 0. 安全边界基准文本（演示前统一读）
- 这是一个前端-only 本地演示。
- 使用的是 selected public sample。
- 不代表 full-web coverage，不代表 full-platform coverage，不代表 full-thread coverage。
- 不代表官方验证，不代表 causal proof。
- 不执行真实平台动作，不调用真实 API，也不调用真实 LLM。
- PeopleCluster 小球是群体簇，不是实名个人。
- InfluenceCore 是内容/叙事核心，不是人球。

## 1. 3 分钟版本

### Shot 1 00:00-00:20 开场
1. 打开 `http://127.0.0.1:5173`。
2. 讲“今天演示的是 Opinion Ecosystem Sandbox，重点看样本驱动下的舆情结构解读”。
3. 3 秒停顿，确认页面可见。

### Shot 2 00:20-00:45 进入沙盒
1. 点击左侧 `生态沙盒 / Opinion Ecosystem Sandbox`。
2. 讲“该模块可选模拟模式，先不触及真实接口”。
3. 暂停 2 秒定位模块区域。

### Shot 3 00:45-01:20 切换样本
1. 依次点击 `Mock schema`、`Evidence fixture mapping`（快速过场）。
2. 选择 `Helldivers PSN sample`。
3. 指向样本状态卡，确认关键文本：
   - selected public sample
   - not full-web coverage
   - not full-platform coverage
4. 停 4 秒让观众看到统计数字。

### Shot 4 01:20-02:00 解读核心可视化
1. 指向 EchoBox，说明它是传播摘要。
2. 指向 PeopleCluster 小球，讲“群体簇，不是具体人”。
3. 指向 InfluenceCore，讲“内容叙事核心节点，不是人球”。
4. 指向 DeconstructionCore、Camp Dynamics、ResponseTempo，解释各自含义。

### Shot 5 02:00-02:35 运行和暂停
1. 点击 Play，说明这是传播推进。
2. 2~3 秒后点击 Pause，定格观察。
3. 解释“暂时不做因果结论，仅用于讨论策略方向”。
4. 点击 Reset，回到起点。

### Shot 6 02:35-03:00 收尾
1. 切到 Mapping contract card，说明 pass/warn/fail 与样本字段约束关系。
2. 重申三条边界：
   - 不代表官方核验
   - 不代表全量覆盖
   - 不代表实时抓取或真实执行
3. 结束语：
“本演示用于透明沟通样本假设与舆情结构，便于做中立化应对讨论。”

## 2. 8 分钟版本

### Shot 1 00:00-00:40 开场与边界复述
1. 先读安全边界基准文本（完整读一次）。
2. 讲今天要展示：样本选择、可视化解读、策略场景切换、输出边界。
3. 停 3 秒，确认所有人看到页面。

### Shot 2 00:40-01:30 进入并确认沙盒
1. 点击 `生态沙盒 / Opinion Ecosystem Sandbox`。
2. 点亮页面说明：当前为前端样本演示，重点是结构演示。
3. 如果出现后端警告，不回避，口头解释“仅展示 local sample 不依赖后端实时取数”。
4. 鼓励观众停留 5 秒确认场景。

### Shot 3 01:30-02:20 样本切换
1. 选择 `Helldivers PSN sample`。
2. 验证样本元数据（34 / 7 / 28 / 6）。
3. 讲“Helldivers 2 / PSN account linking controversy”样本边界。
4. 读出 sample status card：
   - not full-web coverage
   - not full-platform coverage
   - not full-thread coverage
   - not official verification
   - not causal proof
5. 观察并口播“只是一组公开样本片段，不是全网快照”。

### Shot 4 02:20-03:40 模块逐一解释
1. EchoBox：事件摘要与传播意图提示。
2. PeopleCluster：群体结构与聚类分布，不是实名用户。
3. InfluenceCore：叙事核心（内容/官方/媒体/梗传播）枢纽，不是个人。
4. DeconstructionCore：拆解后叙事骨架，帮助识别误读点。
5. Camp Dynamics：分群/分场景变化。
6. ResponseTempo：回应时序变化。
7. ReputationMemory 若可见：用于后续记忆与迭代观察提示。
8. 暂停 30 秒，观众提问预留（不要求互动也可做 10 秒停顿）。

### Shot 5 03:40-05:30 场景演示一（前四个）
1. 点击 Play，进入 `自然演化`，观察 3 秒后 Pause。
2. 说明风险是否自然扩散、群体是否自组织放大。
3. 切 `官方澄清`，解释“澄清可能降低情绪波动但不保证转折”。
4. 切 `FAQ / 长文解释`，说明“结构性解释可提高可理解性，目标是降压与中立化”。
5. 切 `第三方说明`，说明“外部来源可影响叙事修复，但仍需复核来源与时效”。
6. 每个场景都停留 10~15 秒后再切。

### Shot 6 05:30-06:40 场景演示二（后两个）
1. 切 `社区解构`，说明“社区内部重构叙事，常带来反噬风险”。
2. 切 `延迟回应`，说明“迟缓回应可能让讨论曲线更难控平”。
3. 切 `无回应`，解释“沉默阶段的风险是‘未被澄清的叙事继续发酵’”。

### Shot 7 06:40-07:30 复盘与映射合同
1. 再次点击 Pause。
2. 指向 Mapping contract card，讲 pass/warn/fail 与样本适配质量。
3. 若存在 warn，讲“用于风险提示，不作为否定样本的唯一依据”。
4. 重申：不调用真实 API、不抓取 URL 内容、不执行真实平台动作。

### Shot 8 07:30-08:00 收口与结尾
1. 重申 sample status 四条最重要边界。
2. 结尾讲法 A（B 端）：
   “这套展示帮助我们用透明机制把样本和策略关系讲清楚，支持内部评估、跨部门同步和应对沟通预演。”
3. 结尾讲法 B（C 端）：
   “这不是官方验证系统，也不是全平台监测系统；它是一个可解释的舆情结构演示框架，帮助企业更早发现风险节点，提前准备澄清、FAQ 与社区沟通。”

## 3. 不能说的话（避免误解）
- 不要说全网全量、全平台、官方授信、直播抓取、实时取证。
- 不要说“官方 verified Reddit/Steam 数据”。
- 不要说“演示即真实执行”，也不要用“控评”“洗白”“带节奏”等表述。

## 4. 什么时候暂停镜头
- 点击切场景后暂停至少 3 秒。
- 映射卡片显示后暂停 2 秒。
- 样本状态边界说明后再切下一镜至少 5 秒。
- 每个“不能代替人工核验”提示给 2 秒停顿。
