# Boundary Talking Points

Status: safe demo wording only.

Use this document during recordings, C-end sessions, and B-end review calls.

## Core Boundaries

- Sentigraph is not a crawler product.
- Event Plaza is not a real hotlist.
- Dong/Sun is a controlled candidate public sample.
- Helldivers is a selected public sample.
- Sandbox V2 is frontend-only local historical replay.
- PeopleCluster is anonymous aggregate group / behavioral proxy, not a real person.
- InfluenceCore is content / narrative / official / media / KOL / meme core, not people balls.
- No full-web coverage.
- No full-platform coverage.
- No full-thread coverage unless explicitly stated for a sample, and current demo should not claim it.
- No official verification.
- No causal proof.
- No real API or LLM in this demo.
- No real request, vote, support, or sponsorship system.
- Local Exchange Reader is disabled-by-default metadata-only scaffold, not private collector integration.
- Provider output is evidence, not truth.

## Recommended Safe Phrases

- “这是本地 demo / prototype。”
- “这里展示的是 selected sample，不是全网全量。”
- “这部分用于帮助理解历史样本，不是预测未来。”
- “这不是官方验证，只是证据治理和样本解释。”
- “小球是匿名群体簇，不代表真实个人。”
- “核心节点代表叙事或内容核心，不是人。”
- “Request / vote 是 mock 流程，不代表真实热度或真实需求量。”
- “报告样例展示结构和商业价值，不代表已完成生产交付。”

## Avoid These Claims

- “我们已经覆盖全网。”
- “这是实时平台监控。”
- “这是官方验证过的数据。”
- “这能证明因果。”
- “这是实时热榜。”
- “我们能自动抓取所有平台。”
- “系统会自动执行公关动作。”
- “投票数代表真实公众需求。”
- “Local Exchange Reader 已经接入私人 collector。”

## If Asked About Data Sources

Say:

> 当前演示使用受控候选样本或 selected public sample。Sentigraph 负责证据治理、展示、复核和解释。它不会在这个 demo 中运行 crawler、读取真实 exchange 目录、抓取 URL、调用平台 API 或调用真实 LLM。

## If Asked About Business Use

Say:

> B-end 价值在于把样本证据整理成可解释的事件结构、回应节奏、风险机会和建议动作框架。真正上线前仍需要数据授权、合规边界、客户确认和人工复核。
