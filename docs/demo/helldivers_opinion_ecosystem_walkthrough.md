# Helldivers Opinion Ecosystem 走查与演示手册

## 1. 演示目标
- 展示 Sentigraph 的前端本地演示能力：Opinion Ecosystem Sandbox 的样式切换、样本驱动、风险传播模块与安全边界说明。
- 说明当前功能边界：这是一套模拟推演和展示工具，不是完整平台级实时抓取系统。
- 演示场景重点是“可解释的舆情结构拆解”：如何将样本证据映射到群体、核心议题与情境策略。

## 2. 前置条件
- 已启动前端服务，推荐本地访问：`http://127.0.0.1:5173`。
- 建议清空浏览器缓存并使用隐身窗口，避免旧状态干扰。
- 录屏时关闭与本次无关的控制台通知弹窗。
- 可选：启动后端用于完整 Dashboard 数据路径，但 **对本次沙盒演示不是必须**。
  - 后端可选启动命令（如有）：`python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000`
  - 若后端未启动，Sandbox 页面本地样本仍可运行。
- 录屏与口播中不展示任何 `.env` 或密钥。

## 3. 启动与进入页面
1. 打开前端首页：`http://127.0.0.1:5173`
2. 在左侧导航进入 `生态沙盒 / Opinion Ecosystem Sandbox`。
3. 进入页面后先确认顶部/侧边栏样式已正常渲染。
4. 关闭或忽略非沙盒范围的全局状态提示（如果有后端未就绪提示，先说明该系统为演示边界说明）。

## 4. 切换到 Helldivers PSN sample 模式
1. 找到沙盒模式切换区（通常为单选项）。
2. 依次可见并可切换：
   - `Mock schema mode`
   - `Evidence fixture mapping mode`
   - `Helldivers PSN sample`
3. 选择 `Helldivers PSN sample`。
4. 验证样本标题与计数信息：
   - `Helldivers 2 / PSN small public sample`
   - `34 evidence items / 7 sources / 28 comment samples / 6 roots / InfluenceCore candidates`
5. 如果出现“selected public sample / not full-web coverage”等样本状态文本，说明本地样本路径已生效。

## 5. 页面区块说明（演示主线）

### 5.1 EchoBox
- 作用：集中展示“当前事件的传播摘要或舆情主线提示”。
- 说明口径：不是证据真伪判定器，不替代人工核验。

### 5.2 PeopleCluster
- 作用：用小球节点表示“群体簇”。
- 关键边界口径：小球是匿名群体簇，不对应真实个人。
- 演示说法：它用于观察群体结构趋势与聚合行为，不作为个体画像。

### 5.3 InfluenceCore
- 作用：用于表示内容核心、叙事核心、媒体/官方/梗传播节点等“核心叙事轴”。
- 关键边界口径：InfluenceCore 不是小球，不是“人”。
- 演示说法：它是议题/叙事的集中点，强调信息结构，而非个人实体。

### 5.4 DeconstructionCore
- 作用：用于辅助观察“被拆解后的叙事支点”。
- 说明口径：用于辅助解释“叙事可能如何被社区解构”，不是定论。

### 5.5 Camp Dynamics
- 作用：观察不同群体/分叉行为在时间或场景下的相对变化。
- 说明口径：反映的是已导入样本中的群体行为模式，不是外部实时监测总量。

### 5.6 ResponseTempo
- 作用：显示不同应对策略场景中的节奏、反馈路径和传播变化。
- 说明口径：作为演示与讨论工具，不承诺因果关系。

### 5.7 ReputationMemory（若可见）
- 作用：为后续扩展留存“历史回溯线索”。
- 说明口径：当前不等于真实舆情评分系统，不提供真人画像。

### 5.8 Mapping contract card（映射合同卡）
- 核对字段通常包含 pass/warn/fail 数量。
- 重点解释：它说明当前样本映射状态，帮助判断哪些证据字段可用于分析链路。

### 5.9 Sample status card（样本状态卡）
- 重点确认以下安全提示：
  - selected public sample
  - not full-web coverage
  - not full-platform coverage
  - not full-thread coverage
  - not official verification
  - not causal proof

## 6. 交互说明

### 6.1 Play / Pause / Reset
- Play：执行模拟推进，观察传播/聚类/叙事核变化。
- Pause：暂停在当前场景画面，便于讲解节点。
- Reset：重置到当前场景起始状态。
- 演示建议：每个关键场景都做一次 Pause 观察，再切换到下一个场景。

### 6.2 切换场景并逐一讲解
按序执行并口头解释：
- 自然演化
- 官方澄清
- FAQ / 长文解释
- 第三方说明
- 社区解构
- 延迟回应
- 无回应

每次切换都说明：
- 当前是否发生“风险扩散”转向
- 哪些小球群体更活跃
- InfluenceCore 是否有叙事吸引力增强或减弱
- 为什么该场景不能视作官方事实结论

## 7. 不能宣称的内容（重要边界）
- 不要说“覆盖全网”“覆盖全平台”。
- 不要说“官方已验证数据”或“直播爬虫取证”。
- 不要说“因果证明”“该策略一定有效”。
- 不要说“实时抓取 Reddit/Steam/其他平台数据并已核验”。
- 不要说“完成真实平台动作执行”。
- 不要把小球或 InfluenceCore 误导为真实用户身份或官方认证结论。

## 8. 口播安全说明模板（可直接说）
- “这是前端本地演示，使用的是一个公开可见的测试样本，不是全量实时采集。”
- “当前结果用于结构理解和应对讨论，不等同官方认定。”
- “样本是 `selected public sample`，不代表完整网页覆盖，不代表全平台、不代表全线程。”
- “小球表示群体簇，不代表真实单一用户。InfluenceCore 表示内容叙事核心，不是人。”
- “我们默认先做透明讨论：什么能用、什么不能替代人工审核。”

## 9. 常见问题排查

### 9.1 前端没起
- 检查端口 `5173` 是否已监听。
- 检查控制台是否有 build 失败信息。
- 重新启动前端并清缓存访问。

### 9.2 后端 500 提示
- 如果仅是沙盒演示且未用真实后端接口，可先说明“当前为本地样本演示”。
- 建议继续使用 Helldivers 模式检查可视化是否正常加载。
- 若要消除页面顶部后端提示，可启动后端或按项目约定处理全局错误展示策略。

### 9.3 Vite chunk warning
- 常见于构建尺寸提示，通常不影响运行。
- 录屏场景可提示“这是前端打包告警，不影响本功能演示”。

### 9.4 package validator warn（样本规模/跳过来源）
- `warn` 与 `error 0` 说明可用性尚可，但规模与覆盖受限。
- 特别在 Helldivers 小样本中，说明它用于演示验证，不是生产全量覆盖。

## 10. 录屏清单（建议）
- 录屏分辨率保持 16:9，建议 1920x1080。
- 保持每个状态至少停留 3~6 秒。
- 先录 30 秒“安全边界文本”截图，避免误解。
- 至少覆盖：切换模式、mapping contract、sample status、Play/Pause/Reset、所有场景按钮、至少两次场景变化截图。
- 收尾复盘时重申“不代表官方验证 + 不具备因果推断 + 不做真实执行”。
