## Boundaries

- Frontend-only fixed sample report.
- Not production data.
- Not full-web coverage.
- Not full-platform coverage.
- Not full-thread coverage.
- Not official verification.
- Not causal proof.
- Not a judgment of who is right or wrong.
- No report export runtime.
- No PDF / Markdown / briefing deck generation.
- No backend export job.
- No real platform action.
- No real API or real LLM call.
- No collector job was run for these screenshots.

## Known Limitations

- This is a fixed frontend report sample, not a dynamic production report.
- Evidence coverage describes selected available evidence only, not full web or full platform coverage.
- Local historical replay is a sample-based retrospective view, not a prediction and not a complete historical reconstruction.
- Response Strategy Lab is planned-only and not active.
- Export sections are placeholders only; there is no runtime file generation in this screenshot package.
