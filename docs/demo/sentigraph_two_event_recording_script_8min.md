# Sentigraph Two-Event Recording Script - 8 Minutes

## 0:00-0:45 Product Positioning

Click: `/#/demo`

Say:

"Sentigraph is a local public-opinion evidence explanation prototype. It connects public event pages, evidence boundaries, Opinion Ecosystem Sandbox views, and B-end report samples. The current demo uses two event chains: Helldivers / PSN and Dong Lu / Sun Jihai youth football."

What not to claim:

- Do not call it full-web monitoring.
- Do not call it official verification.
- Do not call it production prediction.
- Do not call it a crawler product.

Boundary line:

"Everything shown here is frontend-only and sample-based unless explicitly labeled otherwise."

## 0:45-1:30 Event Plaza and Boundaries

Click: `/#/public-events`

Say:

"Event Plaza is a demo entry list. It is not a real hot list. The page shows events that can be opened into detail pages, sandbox views, and report samples."

Point out:

- Helldivers selected public sample.
- Dong/Sun controlled candidate public sample.
- Request / vote is mock only.

What not to claim:

- Do not say event ranking equals natural public heat.
- Do not say the page is live crawling.

## 1:30-2:45 Helldivers Event Detail and Sandbox

Click:

- `/#/public-events/helldivers-psn`
- `/#/opinion-ecosystem`

Say:

"The Helldivers chain is the earlier international game-community example. It lets us explain a selected public sample through EchoBox, PeopleCluster, InfluenceCore, and local scenario states."

Explain:

- EchoBox: discussion context or resonance container.
- PeopleCluster: anonymous group clusters, not real individuals.
- InfluenceCore: content, official, media, meme, or narrative core, not a person ball.
- Local historical replay: sample-based explanation, not complete reconstruction.

What not to claim:

- Do not say Reddit, Steam, or PlayStation data is officially verified.
- Do not say the replay proves causality.

## 2:45-3:45 Helldivers B-End Report Sample

Click: `/#/reports/helldivers-psn-sample`

Say:

"The Helldivers report sample shows how evidence-backed context can be arranged for internal communication: summary, timeline, risk framing, and response notes. It is a fixed frontend report sample."

Point out:

- Not dynamic report generation.
- Not real export.
- No PDF / Markdown / briefing deck runtime.
- No backend export job.

What not to claim:

- Do not say this is a real client report.
