# Opinion Ecosystem Mock Calculator Integration Boundary v0.1

Status: docs-only / design-only / future deterministic local mock calculator integration boundary. This is not implemented, not runtime, not backend schema, not frontend UI, not tests, not real API, not real LLM, not crawler, not full-web, not full-platform, not official verification, not causal proof, not prediction, not personality diagnosis, not individual persuasion scoring, and not auto-executed response strategy.

Scope is selected sample / local fixture / imported evidence only.

Required model metadata:

- `coefficient_source = mock_default`
- `calibration_status = uncalibrated`
- `empirical_validation = not_started`

## 1. Current Phase Boundary

Phase 8O is docs-only. It creates design references only.

It does not create:

- backend schema
- frontend UI
- calculator code
- tests
- runtime files
- executable fixtures
- production Evidence writes
- production cases
- analysis runs
- B-end report runtime
- Sandbox/public event runtime
- public routes
- public URLs
- signed URLs

## 2. Future 8P Implementation Boundary

If Phase 8P is approved, it must:

- start with tests
- use local synthetic fixtures only
- preserve all model metadata
- preserve all boundary flags
- keep response strategy behind human review
- remain deterministic

It must not:

- read real collector dirs
- parse real `evidence_items.jsonl`
- parse real `evidence_items.csv`
- write Evidence Layer
- create production case
- create `analysis_run`
- generate B-end report runtime
- generate Sandbox/public event runtime
- call real API
- call real LLM
- add public route or delivery
- create public URL
- create signed URL
- fetch URLs
- scrape websites
- use cookies, sessions, browser profiles, tokens, API keys, localStorage, or secrets

## 3. Future Frontend Boundary

If Phase 8Q frontend explanatory UI is approved later, it must:

- show boundary blocks beside scores
- show `coefficient_source = mock_default`
- show `calibration_status = uncalibrated`
- show selected sample / local fixture scope
- show confidence and warnings
- show human review requirement for strategies

It must not:

- imply full-web coverage
- imply full-platform coverage
- imply official verification
- imply causal proof
- imply prediction
- imply personality diagnosis
- imply individual persuasion scoring
- imply auto-executed response strategy

## 4. Future B-End Report Boundary

Future B-end report use must remain human-reviewed.

Report language must keep:

- evidence is evidence, not truth
- sample heat is not real hotlist
- EchoBox is not a real community map
- PeopleCluster is not real person
- InfluenceCore is not people ball
- ResponseStrategy is human-review candidate only

No report should be generated automatically from this model without a separate gate.

## 5. Suggested Future Phases

1. 8O docs-only design complete.
2. 8P deterministic local calculator implementation, if approved.
3. 8Q frontend explanatory UI, if approved.
4. 8R model card QA / screenshot smoke.
5. Later calibration only after historical replay dataset and human review comparison.

## 6. Integration Stop Conditions

Stop if any future task attempts to:

- connect private collector directly
- configure real exchange dirs
- read real collector outputs
- call live platform APIs
- call real LLM APIs
- crawl or scrape
- bypass login, captcha, anti-bot, cookies, or sessions
- expose raw author identifiers
- create public delivery
- output `auto_execute`
- convert uncalibrated scores into final truth claims
