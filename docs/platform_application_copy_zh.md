# 平台应用申请文案

适用对象：抖音开放平台、Bilibili 开放平台及其他平台应用审核材料。

产品名称：归墟舆情分析 / Sentigraph

公司域名：guixutech.com

公司主体：[归墟科技营业执照主体名称]

## 1. 应用简介短版

归墟舆情分析 / Sentigraph 是面向企业的公共舆情证据分析与评论管理辅助工具。系统在用户授权和平台官方接口权限范围内，帮助企业整理公开内容、评论和互动指标，进行证据复核、情绪与话题分析、风险报告和内部预演，不进行未授权抓取、Cookie 登录采集、验证码绕过或反爬绕过。

## 2. 应用简介长版

归墟舆情分析 / Sentigraph 用于企业公共舆情管理、评论反馈整理和风险研判。企业用户可在平台授权范围内接入其有权管理或分析的公开内容、评论、回复和互动指标。系统将平台返回的数据统一规范化为舆情证据记录，并为每条证据保留来源、授权方式、验证状态、信任标签、复核状态和审计记录。

系统提供以下能力：

- 公开评论、回复和内容元数据的规范化整理；
- 舆情证据去重、来源标记和人工复核；
- 评论情绪、话题和风险辅助分析；
- 中文舆情报告和 Markdown 导出；
- 风险趋势研判和内部模拟预演；
- 人工复核队列和审核记录。

系统不绕过平台权限，不采集未授权私有数据，不使用 Cookie 或登录态抓取，不绕过验证码或反爬机制，不自动抓取用户输入的 URL 内容，也不自动执行评论删除、屏蔽、发布、私信或其他真实平台操作。

## 3. 抖音应用说明

### 短版

归墟舆情分析用于企业在获得抖音开放平台授权后，对授权范围内的视频评论和回复进行整理、复核、风险分析和报告生成。系统仅通过官方开放平台接口处理授权数据，不进行页面抓取、Cookie 采集或反爬绕过。

### 审核友好长版

归墟舆情分析计划通过抖音网站应用 OAuth 流程，在企业账号或测试账号授权后，读取授权范围内的用户基础信息和允许访问的视频评论数据。系统使用这些数据进行企业内部舆情证据整理、评论风险识别、用户反馈汇总和报告生成。

申请接口权限的业务目的：

- 帮助企业了解其授权内容下的公开评论反馈；
- 汇总评论中的高频问题、风险话题和情绪倾向；
- 支持人工复核和内部处理建议；
- 形成可追溯的舆情分析报告。

系统不会：

- 获取未授权账号或未授权视频的评论；
- 通过爬虫抓取抖音网页；
- 使用 Cookie、验证码绕过、代理规避或反爬绕过；
- 采集私信、私密内容或与授权场景无关的数据；
- 自动发布、删除、屏蔽、回复或私信用户；
- 对个人用户进行画像、定向影响或诱导。

## 4. Bilibili 应用说明

### 短版

归墟舆情分析用于企业在获得 Bilibili 官方接口权限和账号授权后，对授权范围内的视频、评论或互动反馈进行整理、复核、风险分析和报告生成。系统仅通过官方接口和授权范围处理数据，不进行网页抓取或反爬绕过。

### 审核友好长版

归墟舆情分析计划在 Bilibili 官方开放能力允许的范围内，帮助企业整理其授权内容相关的公开评论、回复、视频元数据和互动指标。系统将这些数据用于企业内部舆情证据分析、用户反馈归纳、风险提示和报告生成。

系统设计原则：

- 仅在官方授权和接口权限范围内处理数据；
- 仅处理企业有权分析的公开内容和评论；
- 保留证据来源、授权方式和复核记录；
- 对重复、低信任或缺少来源的数据进行人工复核；
- 不进行 Cookie 登录抓取、验证码绕过、反爬绕过或隐藏接口访问。

## 5. 权限申请措辞

### 用户基础信息 / user_info

用途：用于识别授权账号、展示授权状态、关联授权范围内的内容与评论分析任务。

说明：系统仅保存必要的授权账号标识和展示信息，用于企业内部权限管理和审计，不用于个人画像或定向营销。

### 评论列表 / item.comment 或平台等价评论权限

用途：用于读取授权范围内内容的公开评论和回复，进行舆情证据整理、风险分析、人工复核和报告生成。

说明：系统只处理授权范围内评论，不读取未授权内容，不读取私信，不自动回复、删除、屏蔽或发布内容。评论数据进入系统后会携带来源、验证状态、信任标签和复核状态。

### 视频/内容列表权限

用途：用于确认企业授权内容、获取内容标题、发布时间、公开 URL 或内容 ID，以便将评论和回复正确关联到对应内容。

说明：系统不通过关键词抓取未授权视频，不绕过 item_id 或内容 ID 来源限制。

### 互动指标权限

用途：用于在舆情报告中展示公开互动指标，如点赞、评论、分享或播放等统计信息，辅助判断事件关注度。

说明：互动指标仅用于聚合分析，不用于个人用户画像。

## 6. item.comment / 评论分析业务说明

归墟舆情分析请求评论相关权限的核心场景是企业评论管理和公共反馈分析。系统读取授权范围内的评论后，会执行以下离线处理：

- 文本清洗与重复识别；
- 情绪倾向与话题归类；
- 高风险评论和争议点提示；
- 代表性评论抽取；
- 人工复核和驳回机制；
- 中文分析报告生成。

该流程不会调用未授权接口，不会抓取网页，不会自动联系用户，不会自动执行平台管理动作。所有风险结果均为企业内部决策辅助，需要人工复核。

## 7. 场景图说明

建议平台审核材料中的场景图包含以下流程：

```text
企业用户登录 Sentigraph
  -> 发起平台官方 OAuth 授权
  -> 平台返回 code / token / 授权范围
  -> Sentigraph 在授权范围内读取内容与评论
  -> 规范化为 EvidenceItem
  -> 去重、信任标记、人工复核
  -> 生成舆情分析报告、风险提示和内部预演
  -> 企业人工审核后决定线下或平台内处理方式
```

图中应明确标注：

- 官方 OAuth / 官方 API；
- 不使用 Cookie；
- 不绕过验证码；
- 不绕过反爬；
- 不抓取未授权页面；
- 不自动执行删除、发布、回复或屏蔽；
- 输出用于企业内部研判和人工复核。

## 8. 合规承诺文案

归墟舆情分析承诺在平台授权和接口权限范围内处理数据。系统不使用爬虫绕过平台规则，不使用 Cookie 或登录态抓取，不绕过验证码、风控或反爬机制，不采集未授权私有数据，不自动执行评论删除、屏蔽、发布、回复或私信动作。系统生成的分析和报告仅用于企业内部辅助研判，需由人工复核后再进行任何业务处置。
