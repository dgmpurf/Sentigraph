## 2. 云服务器要求

- 使用位于中国大陆且支持 ICP 备案的云服务器或云服务商。
- 服务器账号主体应与 ICP 备案主体保持一致或满足服务商备案要求。
- 准备服务器公网 IP、实例信息、服务商备案授权码或备案服务号。
- 确认服务器只部署官网、产品介绍、隐私政策、用户协议、数据授权说明和审核材料入口。
- 不在官网服务器上暴露 `.env`、API Key、Token、Cookie、内部测试数据或客户样本。

## 3. ICP 备案准备

- 准备营业执照、负责人身份证明、手机号、邮箱、主体地址。
- 确认网站名称与经营范围、产品说明一致。
- 官网首页应展示公司和产品介绍，不应出现夸大宣传。
- 页脚预留 ICP 备案号位置：
  - `[ICP备案号待填写]`
- 备案通过前按服务商要求处理访问限制或备案提示页。

## 4. 公安备案

ICP 备案通过后，按所在地要求办理公安联网备案：

- 准备 ICP 备案号；
- 准备网站负责人信息；
- 准备服务器信息；
- 准备域名证书或域名注册信息；
- 页脚预留公安备案号和链接：
  - `[公安备案号待填写]`

## 5. HTTPS 与 DNS

- 为 `guixutech.com` 和 `www.guixutech.com` 配置 DNS A/CNAME 记录。
- 配置 HTTPS 证书并开启强制 HTTPS。
- 检查证书有效期和自动续期。
- 确认隐私政策、用户协议、数据授权说明页面均可 HTTPS 访问。
- 避免在 URL、日志或前端页面中展示任何密钥。

- 首页：产品定位、能力概览、合规边界、联系信息；
- 产品页：证据导入、复核、报告、预演、数据边界；
- 隐私政策；
- 用户协议；
- 数据授权与证据提交说明；
- 平台应用申请说明或审核材料下载入口；
- 联系我们；
- ICP / 公安备案页脚占位。

## 7. 内容边界检查

官网文案不得出现以下表述：

- 已实现全平台真实数据；
- 已实现全网全量采集；
- 抖音、Bilibili 等真实 API 已正式接入；
- RSS/GDELT/搜索发现为实时接口；
- LLM 已真实接入并自动判断真实性；
- 截图或转录内容可自动验证；
- 系统可自动执行删除、屏蔽、发布、回复、私信或平台处置；
- MediaCrawler 已集成；
- 支持 Cookie 抓取、登录绕过、验证码绕过、反爬绕过或代理规避。

推荐表述：

- “合规来源的舆情证据分析”；
- “官方接口或 OAuth 授权后接入”；
- “用户上传或手动录入的数据需要来源确认和人工复核”；
- “趋势和模拟预演用于辅助研判，不保证结果”；
- “当前国内平台真实接口仍以官方审核和权限开通为准”。

## 8. 隐私与协议检查

- 隐私政策包含数据类别、上传证据、手动 URL、供应商样本、授权平台数据、存储删除、用户权利和联系方式。
- 用户协议包含合法使用、用户上传责任、禁止行为、无非法抓取、禁止未授权个人数据提交、服务限制和责任边界。
- 数据授权说明包含用户 attestation、证据复核、截图/转录未验证、驳回证据默认不进入分析、供应商数据为 vendor_attested 而非官方验证。
- 联系方式真实可用。

## 9. 平台审核材料清单

用于抖音、Bilibili 等平台审核时准备：

- 公司官网首页 URL；
- 隐私政策 URL；
- 用户协议 URL；
- 数据授权说明 URL；
- 应用简介短版和长版；
- 权限申请说明；
- OAuth 回调地址，必须为 HTTPS 完整路径；
- 测试账号或审核账号说明；
- 场景流程图；
- 不抓取、不绕过、不使用 Cookie 的承诺说明；
- 数据使用、存储、删除和人工复核说明；
- 联系人、电话、邮箱。

## 10. 平台 reviewer 快速说明

可在审核备注中使用：

```text
归墟舆情分析 / Sentigraph 是企业公共舆情证据分析工具。应用仅在用户授权和平台官方接口权限范围内处理公开内容、评论和互动指标，用于企业内部评论管理、风险研判、报告生成和人工复核。系统不进行网页抓取，不使用 Cookie 登录采集，不绕过验证码或反爬机制，不采集未授权私有数据，不自动执行删除、屏蔽、发布、回复或私信动作。
```

- 每次产品能力变化后同步更新官网、隐私政策、用户协议和平台申请材料；
- 新增真实平台 API 前先完成官方权限、合规、隐私和安全审查；
- 新增供应商前先完成供应商 POC、合同/DPA、删除同步和数据权利审查；
- 保持“不抓取、不绕过、不自动验证、不自动执行真实平台动作”的边界一致。
