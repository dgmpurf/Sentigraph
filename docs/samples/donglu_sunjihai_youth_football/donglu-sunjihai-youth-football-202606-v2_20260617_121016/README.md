# Sentigraph Evidence Export v1 Package

Sample status: `candidate_demo_sample` / controlled candidate public sample.

This copied package is a Sentigraph-side sample intake artifact. It is not production data, not a public C-end event page, not a Sandbox V2 preset, and not a B-end report sample yet.

This package was generated by opencrawler-private as an offline, reviewable Sentigraph Evidence import/demo package.

## Contents

- `manifest.json`: package metadata and safety policy.
- `source_manifest.jsonl`: one row per local source page or source asset.
- `evidence_items.jsonl`: privacy-safe EvidenceItem-like rows.
- `evidence_items.csv`: flattened CSV copy for spreadsheet review.
- `collection_log.jsonl`: export-only action log.
- `coverage_note.md`: sampling and coverage limitations.
- `validation_report.json` / `validation_report.md`: local package validation output.

## Generation Command

`node scripts/export-sentigraph-evidence-v1.mjs --case-id donglu_sunjihai_youth_football_202606 --case-title "Dong Lu / Sun Jihai youth football public-opinion route controversy" --local-snapshot-manifest examples\sentigraph-local-snapshots\donglu_sunjihai_youth_football_202606_v2\manifest.local.json --out exports\sentigraph-evidence-v1 --author-policy hash --strict-privacy true`

## Supported Modes

- Seed URL mode: `--seed-urls examples/helldivers2-psn-sentigraph-seeds.json` samples only the explicit public URLs in the seed file.
- Local snapshot mode: `--local-snapshot-manifest examples/sentigraph-local-snapshots/helldivers2_psn_demo/manifest.local.json` reads manually saved local markdown/text/html/csv files only.
- Local asset mode: `--input data/china-opinion-assets/index.jsonl` converts existing local collector assets.

## Input Source

- examples\sentigraph-local-snapshots\donglu_sunjihai_youth_football_202606_v2\manifest.local.json

## Anonymization Policy

- Raw author IDs are not exported.
- Raw author display names are not exported.
- Profile URLs are not exported.
- Author identity signals are represented only by salted `sha256_platform_case_salt` hashes.
- The private salt is not written to this package.

## Coverage Limitations

This package is selected sample only. It does not imply full-web, full-platform, or full-thread coverage. It is not official verification, not causal proof, and not a judgment of who is right or wrong.

It is also not a complete reconstruction of the public controversy. Live collection and private/restricted content were skipped or limited by safety gates. The sample may be biased by platform availability, safety gates, local/manual snapshot choices, and visible public-source availability.

Minors, families, and sensitive personal details are not exposed. Raw author IDs, raw author display names, profile URLs, cookies, tokens, sessions, and secrets are not exported.

All evidence remains `source_url_provided_unverified` and `review_needed` until a future human review process explicitly approves or rejects items.

## Safety

This package was produced from offline local snapshots. It does not recurse, call platform APIs, launch browsers, use saved browser credentials, or bypass captcha/anti-bot systems.

Sentigraph downstream integration requires a separate audit and development task before this sample can be used for Event Plaza, event detail, Sandbox V2, or B-end report sample work. Private collector capabilities are not Sentigraph built-in crawler capabilities.
