# Sentigraph Evidence Export v1 Package

This package was generated by opencrawler-private as an offline, reviewable Sentigraph Evidence import/demo package.

## Contents

- `manifest.json`: package metadata and safety policy.
- `source_manifest.jsonl`: one row per local source page or source asset.
- `evidence_items.jsonl`: privacy-safe EvidenceItem-like rows.
- `evidence_items.csv`: flattened CSV copy for spreadsheet review.
- `collection_log.jsonl`: export-only action log.
- `coverage_note.md`: sampling and coverage limitations.
- `validation_report.json` / `validation_report.md`: local package validation output.

## Generation Command

`node scripts/export-sentigraph-evidence-v1.mjs --case-id helldivers2_psn_demo --case-title "Helldivers 2 PSN account linking controversy" --local-snapshot-manifest examples\sentigraph-local-snapshots\helldivers2_psn_demo_real_sample\manifest.local.json --out exports\sentigraph-evidence-v1 --author-policy hash --strict-privacy true`

## Supported Modes

- Seed URL mode: `--seed-urls examples/helldivers2-psn-sentigraph-seeds.json` samples only the explicit public URLs in the seed file.
- Local snapshot mode: `--local-snapshot-manifest examples/sentigraph-local-snapshots/helldivers2_psn_demo/manifest.local.json` reads manually saved local markdown/text/html/csv files only.
- Local asset mode: `--input data/china-opinion-assets/index.jsonl` converts existing local collector assets.

## Input Source

- examples\sentigraph-local-snapshots\helldivers2_psn_demo_real_sample\manifest.local.json

## Anonymization Policy

- Raw author IDs are not exported.
- Raw author display names are not exported.
- Profile URLs are not exported.
- Author identity signals are represented only by salted `sha256_platform_case_salt` hashes.
- The private salt is not written to this package.

## Coverage Limitations

This package is selected sample only. It does not imply full-web, full-platform, or full-thread coverage. It is not official verification and is not causal proof.

## Validation Command

`node scripts/validate-sentigraph-evidence-v1.mjs "exports\sentigraph-evidence-v1\helldivers2-psn-demo_20260614_055754"`

## Safety

This package was produced from offline local snapshots. It does not recurse, call platform APIs, launch browsers, use saved browser credentials, or bypass captcha/anti-bot systems.
