# Opinion Ecosystem Sandbox v2 交互视觉规范

本文为 **Opinion Ecosystem Sandbox v2** 的前端交互设计规范，仅作产品/功能设计说明，不构成任何实现承诺。

## 1. 目标 / 目的

Sandbox v2 的目标是把现有模型对象从“静态展示”升级为“可观察、可解释、可演化的舆情生态画布”。

- 将现有原型从“对象列表化”升级为“生态学视觉表达”。
- 让用户在不读文档的情况下理解：
  - EchoBox 在做什么
  - PeopleCluster 的运动和变化含义
  - InfluenceCore 的拉拢/抑制角色
  - 不同场景（官方澄清/FAQ/第三方说明/延迟回应）对舆情生态的影响
- **明确声明**：本规范是设计说明，不是产品实现承诺。

## 2. 当前 v1 局限

- 当前沙箱已能验证对象存在性（EchoBox、PeopleCluster、InfluenceCore），但生态动力不够明显。
- EchoBox 尚未形成“讨论容器优先”的视觉中心，容易被核心节点主导。
- InfluenceCore 尚未统一成为明确的“叙事/观点重力核”。
- PeopleCluster 的移动和转移节奏较弱，变化不够直观。
- “响应节奏”目前以按钮为主，缺少时间轴化叙事。
- 外部变量/事件未被作为一等公民可视化展示，更多停留在文本触发。

## 3. 设计原则

1. **视觉先行、解释随后**  
   先看到“发生了什么”，再读说明与数值。
2. **C 端可读性优先**  
   C 端用户应靠图形语义判断“舆情热度、群体倾向、变化方向”，不要求阅读长说明。
3. **B 端可分析性保留**  
   B 端用户能快速识别关键模型信号：核心叙事来源、去向、风险点。
4. **对象边界必须稳定且可区分**  
   - **PeopleCluster** = 匿名群体/群体簇（小球）
   - **InfluenceCore** = 内容/叙事/官方/媒体/梗点核心（非人类节点）
   - **EchoBox** = 讨论边界/容器
5. **安全边界清晰**  
   不出现“操控”、“全网抓取证明因果”“官方全量已验证”等过度表述。

## 4. 画布布局 v2

- **主舞台**：大尺寸正方形/矩形 EchoBox，作为主讨论容器。
- **左侧说明区**：对象图例、当前场景、颜色/形态含义（便于 C 端理解）。
- **顶部控制区**：场景选择、时间轴播放、对比选项。
- **右侧/底部指标区**：仅显示关键状态指标，不夺目干扰视觉主体。
- **右下可选小地图**：用于多 EchoBox 模式（后续版本），显示跨区连接关系。
- **全屏/聚焦模式**：放大主舞台，仅保留关键控制与最小状态面板。

## 5. EchoBox v2

### 视觉定义
- **尺寸**：承载样本规模与潜在影响范围的“容量”
- **边界粗细**：边界越厚代表舆论回音越强。
- **边界开口/缺口**：代表可渗透区（向外扩散或外部输入）。
- **边界脉冲**：显示外溢风险/突破风险。
- **内部密度**：颜色堆积程度表示饱和度（讨论浓度）。
- **边缘裂缝/通道**：表示突破路径或跨盒连接尝试。
- **扩张 / 收缩**：表达事件生命周期中的热度放大或衰减。

### 多容器（MVP 后扩展）
- 核心社区盒
- 外围公开讨论盒
- 媒体/说明盒
- 梗解构盒

## 6. PeopleCluster v2

### 视觉语义
- 小球形状代表匿名群体簇，不代表单个真实用户。
- 配色建议：
  - 支持：绿色
  - 中立：灰色
  - 反对：红色
  - 摇摆：黄色
  - 桥接/高传播潜力：紫色
  - 退出/衰竭：半透明灰白
  - 休眠高风险：深色轮廓强化
- 尺寸：群体规模/影响权重。
- 速度：活跃度。
- 外发光：情绪负荷。
- 透明度：疲劳或撤离程度。
- 边框：高风险 / 关键桥接 / 异常提醒。

### 行为规则（可视化）
- 同阵营弱吸引、异阵营排斥（Bridge 条件下可放宽）。
- 中立群体受强核心吸引。
- 高身份锁定群体色变不易，低锁定群体可渐变。
- 疲劳增强时逐步淡出并向边缘游离。
- 休眠簇可在触发后短暂复现。

## 7. InfluenceCore v2

### 核心定义
InfluenceCore 为“叙事引力源”，不是人群球体，包含：
- 官方表述
- 媒体文章
- 社区讨论节点
- 创作者内容
- 第三方说明
- 梗/解构核心
- 病毒式普通内容

### 视觉
- 大于 PeopleCluster 的非圆形节点（可用菱形/十字或专属 icon）。
- 不同角色用边框与标识区分（官方/媒体/社区/梗/反向解释）。
- 影响力半径（aura）可见化。
- 可信度、极化程度、去梳理标记可通过环形状态条表现。

### 交互效果
- 吸引匹配方向群体。
- 可中和部分轻度对立簇。
- 在对立阻力高时加重对方硬化。
- 能吸引中立群体并触发疲劳/撤离。
- 强弱随时间变化（可受事件影响衰减或增强）。

## 8. Camp Dynamics v2

状态转移（可见动画）：
- **同化（Assimilation）**：颜色渐趋同阵营色。
- **中和（Neutralization）**：红/绿向灰靠拢。
- **撤离（Withdrawal）**：透明度降低并移向边界外。
- **硬化（Hardening）**：颜色加深、运动固定、靠近核心。
- **反噬（Backlash）**：偏离策略后，灰/绿群体向对立核回流。
- **再激活（Reactivation）**：休眠球群在触发事件下再上场。

产品文案需使用安全词：
- “趋同”/“中和”/“复燃”/“风险变化”/“分流”
- 避免任何“洗白/控评/带节奏/操控/猎食”等表述。

## 9. 外部变量 / 冲击事件 v2

首级事件 token（可重复触发）：
- 官方澄清
- FAQ / 长文解释
- 第三方说明
- 媒体放大
- 新证据出现
- 头部创作者/主播发声
- 平台推荐增量
- 社区梗化/解构
- 延迟回应
- 无回应（基线）

可视化结果：
- 事件从容器外进入场景。
- 可能生成新 InfluenceCore。
- 可能打开/收紧 EchoBox 边界。
- 可能连通多个 EchoBox。
- 改变内部饱和度与撤离率。
- 可能触发再激活。

## 10. 响应节奏时间轴 v2

- 以时间轴替代纯按钮驱动为主视图：
  - **T0** 事件触发
  - **T1** 反噬形成
  - **T2** 官方回应
  - **T3** 第三方说明
  - **T4** 去梳理窗口
  - **T5** 疲劳/衰减
  - **T6** 记忆残留
- 功能要求：
  - 可拖拽时间游标
  - 场景标记点可跳转
  - 对比“自然演化 / 官方澄清 / FAQ / 社区解构 / 延迟回应 / 无回应”
  - 现有按钮保留为快捷预设，不冲突

## 11. 多 EchoBox v2

- v2 首版：单一盒子主体验证可用性。
- 进阶版本：  
  - 社区盒（Steam/Reddit/其他社媒）  
  - 媒体盒  
  - 说明与澄清盒  
  - 梗解构盒
- 支持桥接通道与跨盒迁移。
- 可视化显示“突破风险”与跨域流动方向。

## 12. 指标与信息卡 v2

指标卡保持最小化，服务于解释：
- 阵营分布
- 中和率
- 撤离率
- 反噬风险
- 破壁风险（边界突破）
- 回音室强度
- 饱和度
- 去梳理窗口
- 休眠风险
- 样本覆盖说明（非全量声明）

## 13. C 端解读引导

- 小球不是真实用户，是群体簇抽象表示。
- 球体颜色是立场/情绪趋势，不是个人身份标签。
- 小球变大并非真实粉丝数，而是影响权重示意。
- 边界更亮更密 ≠ 真实传播量，只是样本内可见强度。
- InfluenceCore 表示内容/叙事/来源中心，不表示任何单一人。
- 鼓励按钮词：
  - “查看样本说明”
  - “查看安全边界”
  - “暂停观察”
  - “重置并对比”

## 14. B 端解读引导

B 端看图时应聚焦：
- 哪个 InfluenceCore 在主导讨论流向
- 哪些群体已被中和或硬化
- 是否有“未触达群体”滞留在边界外
- 热度是否被困在单个 EchoBox
- 响应是否偏早/偏晚
- 是否存在可见的去梳理窗口
- 残留风险是否继续存在

输出建议：用于讨论与方案评估，不用于个体识别、定向操控。

## 15. 数据与模型边界

v2 第一版必须保持：
- **前端本地静态样本演示**为主
- 不接后端导入流程（当前阶段）
- 不调用真实 API
- 不调用 LLM
- 不抓取真实平台内容
- 可复用现有本地 fixture
- 明确展示安全边界文案：
  - 选定公开样本
  - 非全网覆盖
  - 非全平台覆盖
  - 非全线程覆盖
  - 非官方实证
  - 非因果结论证明

## 17. 非目标（本阶段不做）

- 不改后端 schema
- 不引入生产级模拟
- 不接真实平台 API 或 RSS/GDELT 搜索
- 不提供“真实舆论控制”能力
- 不做用户级别劝服分值
- 不新增爬虫能力（包括 cookie / 登录 / 验证码绕过 / 反爬）
- 不引入第三方技能执行的隐私敏感链路

## 18. v2 原型验收标准（实施前）

- 用户可在视觉上区分 EchoBox、PeopleCluster、InfluenceCore。
- Helldivers 样本可进入并在 v2 模式正常运行。
- 场景或时间轴变化能明显影响轨迹/颜色/透明度/边界状态。
- 样本边界与安全说明始终可见且不易遗漏。
- 无网络请求（演示版运行不依赖真实接口）。
- 控制台关键报错为 0（除浏览器通用 warning 外）。
- 老模式可继续访问，或在同路由平滑替换为 v2 行为。
