## 产品摘要

归墟舆情分析 / Sentigraph 是一套面向品牌、公关、合规、客服、运营和风险管理团队的舆情证据分析工具。系统围绕“事件”组织证据，将评论、文章、帖子、回复、互动指标、人工录入内容、CSV/Excel 上传样本和未来官方接口数据统一为可追溯的 EvidenceItem 记录。

平台当前定位为企业内部分析与演示验证系统。分析、风险研判、报告、预测和模拟预演为离线确定性流程或经授权数据处理流程，不代表平台官方结论，也不保证未来事件结果。

## 适用用户

- 品牌与公关团队：快速整理事件舆情证据，生成内部研判报告。
- 客服与用户运营团队：汇总用户反馈、评论与投诉线索，识别高频问题。
- 合规与风控团队：保留证据来源、复核记录和处理边界，避免未授权采集。
- 市场与产品团队：分析公开讨论中的需求、争议点和改进方向。
- 咨询与研究团队：基于合法样本完成事件级公共意见分析。

## 核心功能

### 证据导入与归一化

支持人工 URL 证据、CSV/Excel 用户上传样本、供应商样本 POC、静态搜索发现候选、公开平台官方接口或未来 OAuth 授权数据的统一证据建模。导入过程不执行公式，不保存原始上传文件为默认行为，不读取凭证，不自动抓取 URL。

### 信任、去重与复核

每条证据可携带来源类型、采集方式、验证状态、信任标签、用户授权说明、风险标记、内容哈希和重复组信息。截图、转录文本、人工录入和供应商样本不会被自动视为已验证。

### 舆情分析与报告

系统基于可用证据生成离线确定性的情绪、话题、风险与中文报告，并可导出 Markdown 报告。报告用于辅助分析，不构成事实认定、法律意见或结果保证。

### 风险监测与趋势研判

系统可基于本地案例快照进行风险趋势和预警研判。该能力用于辅助判断和复盘，不代表对未来结果的确定预测。

### 模拟预演

Simulation Lab 支持聚合层面的情景预演和策略对比，用于内部讨论不同沟通方案的潜在影响。它不执行任何真实平台操作，不自动发布、删除、屏蔽或定向影响个人。

### 平台接入准备

系统保留官方 API、OAuth 授权、数据供应商和用户上传样本等合规接入路径。当前国内平台真实接口仍需以平台官方审核、权限范围、回调配置和测试账号授权为准。

## 数据来源说明

归墟舆情分析支持以下合规数据入口：

- 用户手动录入的公开 URL、标题、正文、评论或摘要；
- 用户上传的 CSV/Excel 样本；
- 经过合规审核的供应商样本文件；
- 搜索发现候选的 URL / 标题 / 摘要元数据；
- 已获授权和批准的官方平台 API 或 OAuth 数据；
- 本地演示或测试用 mock fixture。

当前可选 YouTube 真实数据路径仅用于本地授权演示，需要本地配置官方 YouTube Data API Key；自动化测试不会调用真实 YouTube API。抖音、Bilibili、小红书、微博等平台的真实接口接入仍处于官方权限、OAuth、回调地址、测试账号或评论权限审核阶段。

## 合规边界

归墟舆情分析不提供以下能力：

- 未授权私有数据采集；
- Cookie / 登录态抓取；
- 验证码绕过；
- 反爬机制绕过；
- 代理规避或隐藏采集；
- MediaCrawler 或类似源码爬虫作为生产数据源；
- 自动抓取用户输入 URL 的网页内容；
- 自动验证截图或转录文本真实性；
- 自动执行内容审核、删除、屏蔽、发布或真实世界处置动作；
- 针对个人的影响力画像、诱导或定向说服。
