## 1. 服务说明

归墟舆情分析 / Sentigraph 是企业公共舆情证据分析工具，提供证据导入、归一化、去重、信任标记、人工复核、审计记录、分析报告、风险研判和模拟预演等能力。

本服务用于企业内部分析、风险研判、报告辅助和合规复核，不构成事实认定、法律意见、投资建议或对未来结果的保证。

用户使用本服务时，应仅提交其有权处理的公开信息、授权信息、供应商样本或企业内部合法数据。
