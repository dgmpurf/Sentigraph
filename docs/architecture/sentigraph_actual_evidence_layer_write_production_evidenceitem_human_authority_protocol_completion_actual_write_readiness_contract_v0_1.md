The future 9A-8 gate, if separately approved, may define declaration structure only.

## G. Actual Write Separation

Actual Evidence Layer write remains separated from 9A-7 and any future docs-only 9A-8 declaration gate.

- a new exact approval phrase
- explicit human authority provided by a human outside Codex

- risks classified
- input lineage verified
- raw/private/secret absence confirmed
- audit/rollback/revocation plan
