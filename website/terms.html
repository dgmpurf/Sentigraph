1. 服务说明

归墟舆情分析 / Sentigraph 是企业公共舆情证据分析工具，提供证据导入、归一化、去重、信任标记、人工复核、审计记录、分析报告、风险研判和模拟预演等能力。本服务不构成事实认定、法律意见、投资建议或对未来结果的保证。

2. 合法使用要求

用户应确保使用本服务时遵守适用法律法规、平台规则、合同约定和数据来源授权。用户应对其上传、录入、导入、提交或授权处理的数据来源合法性、使用权利和内容合规性负责。

3. 用户上传数据责任

  • 上传或录入的数据不会自动被视为真实、完整或已验证。

  • 用户不得提交 API Key、Cookie、访问令牌、client secret、密码、私信、私密群组内容、登录态数据或付费墙内容。
  • 用户应根据业务需要和法律要求处理删除、纠错、授权撤回和数据保留事项。

4. 禁止使用行为

  • 非法收集、处理、出售或传播个人信息。
  • 未经授权采集平台数据。
  • 使用 Cookie、账号密码、登录态、验证码绕过、反爬绕过、代理规避或隐藏接口访问。
  • 将 MediaCrawler、OpenClaw 或其他外部工具集成为 Sentigraph 生产数据源。
  • 提交私信、私密群组、非公开账号数据、付费墙内容或受限内容。
  • 使用分析结果进行个人定向说服、骚扰、歧视、操纵或不当影响。
  • 自动执行真实内容发布、删除、屏蔽、封禁、私信、营销或平台操作。

5. 数据边界

Sentigraph 不提供未授权爬取能力，不自动抓取用户输入 URL 内容，不使用 Cookie 登录抓取，不绕过验证码或反爬机制，不集成 MediaCrawler 作为核心数据源。当前产品的国内平台真实接口接入仍以平台官方审核、OAuth 授权、权限范围、测试账号和回调地址配置为准。

6. 分析结果限制

系统生成的情绪、话题、风险、报告、趋势和模拟预演结果基于当前可用证据和确定性规则，仅用于辅助判断。用户应结合人工判断、业务背景、法律合规和平台规则进行决策，不得将系统输出作为唯一依据。
