产品能力

归墟舆情分析 / Sentigraph 将企业合法获得或经授权获取的公共舆情材料，转化为结构化、可追溯、可复核的证据记录。

证据导入与归一化

系统围绕事件组织证据，支持文章、帖子、视频、标题、正文、评论、回复和互动指标等材料的统一建模。每条证据都保留平台、来源类型、采集方式、证据类型、URL、时间、互动指标、安全元数据和导入元数据。

CSV / Excel 导入

企业可上传合法来源的 CSV 或宏关闭的 Excel 样本。系统提供预览、字段映射、导入确认、重复检测和安全警告。导入过程不执行公式，不保存原始上传文件为默认行为，不读取凭证。

人工 URL 证据

用户可手动录入公开 URL、标题、正文、评论、作者标签、发布时间和指标。系统不会自动访问、抓取或解析该 URL，URL 仅作为来源上下文和人工复核线索保存。

搜索发现候选

当前 Search Discovery、RSS Mock 和 GDELT Mock 仅提供本地静态 URL / 标题 / 摘要候选，用于演示候选复核流程。它们不是实时搜索、RSS 或 GDELT 接口。

信任、去重、复核与审计

Sentigraph 不把所有证据视为同等可靠。系统会记录 provenance_type、verification_status、trust_label、source_url_present、user_attestation_required、risk_flags、duplicate_group_id 和 duplicate_count。

低信任、未验证、截图转录、缺少来源、缺少授权确认、重复或存在风险标记的证据会进入人工复核队列。复核动作包括通过、驳回、标记为弱证据、要求补充来源、合并重复和重置复核状态，并形成审计时间线。

分析、报告、预测与模拟预演

系统可基于当前案例中的可用证据生成情绪、话题、高风险议题、重复话术提示、代表性文本、中文舆情分析报告和 Markdown 导出。风险趋势和 Simulation Lab 为离线确定性辅助能力，用于内部讨论和人工复核，不保证未来结果，也不执行真实平台操作。

当前边界

  • 默认运行在 mock/offline 模式。
  • YouTube 真实数据仅作为本地可选演示，需要官方 YouTube Data API Key。
  • 抖音、Bilibili、小红书、微博、Reddit 等真实接口仍待官方权限、OAuth、回调地址、测试账号或接口范围确认。
  • LLM provider 当前为 mock，不调用真实大模型 API。
  • MediaCrawler、OpenClaw 等外部工具不作为产品核心采集器或生产数据源。
  • 用户上传、人工录入、供应商样本和截图转录不会被自动视为已验证。

适合场景

品牌危机复盘、产品反馈分析、评论管理准备、供应商样本 POC、舆情策略预演。

重要说明

系统输出用于企业内部辅助研判，需要结合人工、业务、法律和平台规则复核。
