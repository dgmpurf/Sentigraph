归墟舆情分析 / Sentigraph

面向企业的公共舆情证据分析、评论管理、风险报告、证据复核与模拟预演平台。

系统帮助企业把合规来源的公开评论、文章、视频说明、用户上传样本和授权数据整理为可复核的舆情证据，用于内部分析和风险研判。

了解产品能力 查看数据边界

合规边界优先

  • 不进行未授权私有数据采集。
  • 不使用 Cookie、登录态、验证码或反爬绕过。
  • 不自动抓取用户输入的 URL 内容。
  • 上传、人工、供应商证据不会被自动视为已验证。

为企业舆情决策建立可追溯证据层

Sentigraph 围绕“事件”组织证据，将不同来源的公开材料统一为可去重、可复核、可审计的 EvidenceItem。

证据导入

支持人工 URL 证据、CSV/Excel 上传样本、供应商 POC 样本、搜索发现候选和未来官方授权数据的统一证据建模。

信任与复核

为证据保留来源、采集方式、验证状态、信任标签、重复组、风险标记和人工审核记录。

分析与报告

基于可用证据生成情绪、话题、风险、中文报告、趋势研判和聚合层面的 Simulation Lab 预演。

适用团队

面向需要审慎处理公开舆情证据、评论反馈和风险报告的企业组织。

品牌与公关

整理事件舆情证据，识别争议点，形成内部研判报告。

客服与运营

汇总用户反馈、投诉线索和高频问题，辅助改进沟通与服务。

合规与风控

保留数据来源、复核记录和使用边界，降低未授权采集风险。

数据来源说明

系统支持合规来源下的证据整理，不把候选线索、截图、供应商样本或人工录入内容自动视为真实事实。

来源当前定位说明
用户上传 CSV/Excel可用用户需确认来源合法；系统只保存规范化证据和安全元数据。
人工 URL 证据可用URL 作为来源线索保存；系统不会自动访问或抓取网页内容。
供应商样本POC 路径用于字段、来源、合规和成本评估；不是平台官方验证数据。
YouTube 公开数据可选本地演示仅在本地配置官方 YouTube Data API Key 时使用；自动化测试不调用真实 API。
抖音 / Bilibili 等待官方权限真实接口仍需平台审核、OAuth、回调地址、测试账号和评论权限确认。

我们不提供的能力

Sentigraph 不提供未授权私有数据采集、Cookie/登录态抓取、验证码绕过、反爬绕过、代理规避、MediaCrawler 生产集成、自动 URL 抓取、截图真实性自动验证、自动内容处置或个人定向影响能力。
