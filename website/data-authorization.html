数据授权与证据提交说明

用户提交数据前，应确认来源合法、用途合规，并理解上传、人工、供应商和截图证据不会自动被视为已验证。

可以提交的数据

  • 公开文章、新闻、帖子、视频说明或评论的 URL、标题、正文、摘要。
  • 公开评论、回复、用户反馈或投诉文本。
  • 与事件相关的互动指标，如点赞、回复、分享、浏览量。
  • 企业合法取得的 CSV/Excel 样本。
  • 第三方供应商在 POC 中提供且不含密钥的样本文件。
  • 经过平台官方授权或 OAuth 授权后可处理的数据。

不应提交的数据

  • 未经授权的个人信息或敏感个人信息。
  • 私信、私密群组、非公开账号内容。
  • 登录态数据、Cookie、Token、账号密码、client secret、API Key。
  • 付费墙、会员区、未授权下载或受限内容。
  • 通过验证码绕过、反爬绕过、代理规避、隐藏接口或 Cookie 抓取得到的数据。

用户授权确认

我确认对所提交的公开舆情证据拥有合法来源或使用权，并同意将其用于归墟舆情分析 / Sentigraph 的证据归一化、风险分析、报告生成和人工复核。

如果用户未完成授权确认，系统可继续保存必要的规范化证据，但会降低信任标签并标记为 needs_review 或 user_attestation_missing。

手动证据与可选授权平台数据

手动 URL 证据由用户自行提供标题、正文、评论或摘要。系统不会自动访问该 URL。未来平台官方 API 或 OAuth 数据必须在平台审核、权限范围、回调地址、测试账号和令牌配置完成后处理。

供应商样本数据

供应商样本应标记为 data_vendor。vendor_attested 表示供应商对来源或授权作出说明，不表示平台官方已验证内容，也不表示证据本身一定真实。供应商数据仍需经过字段完整性、重复率、来源可追溯性、删除同步、个人信息处理和合同权利复核。

证据复核原则

低信任、未验证、截图转录、缺少来源、缺少授权确认、重复提交或包含风险标记的证据会进入人工复核队列。人工复核中被驳回的证据默认不进入后续分析、代表性评论和报告正文。

截图和转录说明

截图、截图转录、人工复制文本和外部工具辅助整理文本不会被系统自动验证。系统不会使用 AI 自动判断截图真实性，也不会把截图内容称为平台官方验证数据。
